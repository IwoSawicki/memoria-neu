# Downloads – Katalog austauschen

Hier liegt der Katalog, der auf der Seite **Tierurnen & Andenken** eingebunden ist.

## Katalog aktualisieren

1. Neue PDF-Datei exakt so benennen: **`tierurnen-katalog.pdf`**
2. Die vorhandene Datei in diesem Ordner damit ersetzen (überschreiben).
3. Änderung committen und pushen – beim nächsten Deploy ist der neue Katalog live.

Mehr ist nicht nötig: Der Dateiname ist im Code fest hinterlegt, es muss also
**nichts am Code geändert** werden. Auf der Seite wird die PDF automatisch
eingebettet und über die Buttons „Katalog öffnen" und „Katalog herunterladen"
verlinkt.

> Falls die Datei einmal anders heißen soll, kann der Pfad zentral in
> `src/data/site.ts` unter `katalogPdf` angepasst werden.

## Aktueller Stand

⚠️ **Die aktuell hinterlegte Datei ist nur ein Platzhalter.** Bitte vor dem
Livegang durch den echten Katalog ersetzen.
